出网模式 总开关

决定本工作台所有对外探测流量的出口：直连 / 经代理池 / 经 Tor 出口。三选一，保存后立即生效——不仅自带的 http 工具，技能自建的请求（requests / aiohttp）与 curl/sqlmap/nuclei 等子进程也会遵循。例外：nmap、端口扫描、DNS、WHOIS、TLS 握手属 TCP 直连，HTTP 代理无法转发，目标侧会看到本机真实 IP。

扫描速率 / 隐蔽性 限速中

批量扫描限速：令牌桶（全局 + 单主机）+ 随机抖动 + 并发闸门，避免请求过于密集被识别或打挂业务。扫描类技能的并发线程数也会被封顶；命令类工具会注入 nmap --max-rate / nuclei -rate-limit 等参数。
